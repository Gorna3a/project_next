# Quick Reference Summary

## Core Terminology / Formula Matrix
| Term / Command | Definition / Formula | Common Usage |
| :--- | :--- | :--- |
| **ECMAScript** | The standard that defines JavaScript | Checking which features exist in which version |
| **console.log** | Prints values to the output | Inspecting values while debugging |
| **Node.js** | Runtime that runs JavaScript outside the browser | Running scripts from the terminal |

## Key Concepts Comparison
- **Browser JavaScript** vs. **Node.js**: browsers control web pages; Node.js works with files and networking.

## Critical Syntax / Templates

// comment
console.log("text", 42);
