# Questions

## Question 1
<!-- meta: {"type":"single","points":1} -->
Which language standard defines how JavaScript behaves in every browser?

- [ ] CSS
- [x] ECMAScript
- [ ] HTTP
- [ ] JSON

*Explanation*: ECMAScript is the specification that all JavaScript engines follow.

## Question 2
<!-- meta: {"type":"single","points":1} -->
Which function prints a value to the console?

- [ ] print()
- [ ] echo()
- [x] console.log()
- [ ] write.out()

*Explanation*: console.log is the standard way to output values while developing.

## Question 3
<!-- meta: {"type":"multiple","points":2} -->
Where can JavaScript run? Select all that apply.

- [x] In a web browser
- [x] In Node.js
- [ ] Only inside Java programs
- [x] In some mobile and desktop apps

*Explanation*: JavaScript runs in browsers, Node.js, and embedded runtimes. It is not limited to Java programs.

## Question 5
<!-- meta: {"type":"true-false","points":1} -->
A single-line comment starts with two forward slashes.

- [x] True
- [ ] False

*Explanation*: Everything after // on that line is ignored by the engine.

How do you run a file named app.js with Node.js?

- [ ] run app.js
