# Course Overview

JavaScript is the language of the web. It runs in every browser, powers servers through Node.js, and is the first language many developers learn because you can see results immediately.

This course takes complete beginners from their first line of code to confident, practical programmers. Every module combines short lessons with guided workshops and independent labs that are graded automatically.

## Learning Objectives
- Write and run JavaScript programs in the browser and in Node.js
- Use variables, types, operators, and control flow correctly
- Design reusable functions and model data with arrays and objects
- Handle errors and write asynchronous code with promises

## Prerequisite Knowledge
- None. Basic computer literacy only.
