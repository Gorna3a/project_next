# Module Overview

This module gets you set up and writing code on day one. You will learn where JavaScript comes from, how its versions work, and three ways to run it.

By the end you will have printed your first messages to the console and be ready to learn variables in Module 2.

## What You Will Be Able To Do
- Explain what JavaScript is and where it runs
- Run a script in the browser console, a page, and Node.js
- Print values with `console.log`
