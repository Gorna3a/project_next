# Module Overview

Module 4 taught you to compute and compare values. Now your programs need to choose between actions and repeat work. This module covers branching with `if`, `else if`, `else`, and `switch`, then repeats code with `for`, `while`, and `do...while` loops.

You will also learn to steer loops with `break` and `continue`, including inside nested loops. The workshop builds the classic FizzBuzz exercise and a running sum, and the lab prints a number triangle. These exercises expose the two most common loop bugs: running one step too far and never stopping.

## What You Will Be Able To Do
- Branch with `if`, `else if`, `else`, and `switch`
- Repeat code with `for`, `while`, and `do...while`
- Control loops with `break` and `continue`, including nested loops
- Avoid off-by-one errors, infinite loops, and switch fallthrough bugs
