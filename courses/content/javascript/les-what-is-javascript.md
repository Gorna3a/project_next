# Concept Overview

JavaScript is a programming language created in 1995 to make web pages interactive. Today it runs in browsers, on servers, and inside desktop and mobile apps. It is standardized as ECMAScript, which means every browser agrees on how the language behaves.

## Key Principles & Frameworks

JavaScript is interpreted: an engine reads your code and runs it directly, without a separate compile step you manage yourself. It is also dynamically typed, so a variable can hold different kinds of values over time. Three places you will meet it: the browser (web pages), Node.js (servers and tools), and embedded runtimes (apps and devices).

```js
// Your first line of JavaScript
console.log("Hello from JavaScript!");
```

## Common Pitfalls & Anti-Patterns
- **Java is not JavaScript**: The names are similar, but they are different languages with different uses.
- **Browser and Node.js differ**: Browsers have a page to control; Node.js has files and networking instead.

## Quick Summary
- JavaScript runs in browsers, on servers, and in apps.
- ECMAScript is the standard that all engines follow.
