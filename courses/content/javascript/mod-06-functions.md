# Module Overview

Control flow lets a program decide and repeat. Functions let you package a piece of behavior, name it, and reuse it. This module starts with function declarations and expressions, then moves to arrow functions, default and rest parameters, and recursion.

Functions are the building blocks of every larger program. You will learn how values enter a function as parameters, how results leave through `return`, and how a function can call itself to solve a problem in smaller steps. The workshop builds a small utility library, and the lab implements three classic recursive algorithms.

## What You Will Be Able To Do
- Declare functions, call them, and return values
- Use arrow functions with block bodies and implicit returns
- Accept flexible input with default parameters, rest parameters, and spread
- Solve problems with recursion and a correct base case
- Use IIFEs, the `arguments` object, and common built-in functions
