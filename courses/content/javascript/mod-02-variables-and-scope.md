# Module Overview

Module 1 taught you to run code and print output. This module teaches you to store values in variables and control where those variables are visible. You will learn the three declaration keywords, the rules for naming variables, how block scope works, and why using a variable too early can fail.

These ideas appear in every program you will ever write, so take your time with the workshops and labs before moving on to data types in Module 3.

## What You Will Be Able To Do
- Declare variables with `var`, `let`, and `const`, and choose the right one
- Name variables legally using camelCase conventions
- Predict whether a variable is visible at a given line using scope rules
- Avoid hoisting surprises and accidental global variables
