# Module Overview

Real programs work with collections: lists of scores, records of users, inventories of products. This module introduces arrays for ordered lists and objects for named fields, then shows how to transform and inspect them with methods such as `map`, `filter`, and `reduce`.

You will also learn when to use `for...of` and `for...in`, how `Map` and `Set` differ from plain objects and arrays, and how to convert structured data to and from JSON. The workshop processes student records, and the lab builds an inventory report that returns JSON.

## What You Will Be Able To Do
- Create, index, and modify arrays with `push`, `pop`, `slice`, `splice`, and destructuring
- Transform arrays with `map`, `filter`, `reduce`, `find`, `some`, `every`, and `sort`
- Model data with object literals, spread, destructuring, and `Object.keys`/`values`/`entries`
- Iterate collections correctly with `for...of` and `for...in`
- Use `Map`, `Set`, and JSON to store and exchange structured data
