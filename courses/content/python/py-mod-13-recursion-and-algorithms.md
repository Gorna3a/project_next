# Module Overview

This module teaches you to solve problems by breaking them into smaller subproblems and to judge how well those solutions scale. You will learn how recursion works, how the call stack supports it, and how memoization avoids repeating work.

You will then learn to analyze time and space complexity with Big-O notation. From there you will study searching algorithms, including linear search and binary search, and sorting algorithms, from simple elementary sorts to efficient divide-and-conquer sorts such as merge sort and quicksort.

## What You Will Be Able To Do
- Write recursive functions with correct base cases
- Explain the call stack and the recursion limit
- Apply memoization to avoid repeated work
- Estimate time and space complexity with Big-O notation
- Implement linear search and binary search
- Compare bubble, selection, and insertion sort
- Explain the difference between `sorted` and `list.sort`
- Describe merge sort and quicksort and compare their complexities
