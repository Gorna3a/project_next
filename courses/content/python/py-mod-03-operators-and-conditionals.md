# Module Overview

Programs become useful when they can make decisions. That requires two things: operators that produce and compare values, and control flow that runs different code depending on the result.

This module covers Python's arithmetic, assignment, comparison, identity, membership, and logical operators. You will learn how precedence and short-circuit evaluation work, then use those results in `if`, `elif`, `else`, and `match` statements. The workshop and lab turn the rules into small decision-making scripts.

## What You Will Be Able To Do
- Use arithmetic operators, including floor division, remainder, and exponentiation
- Apply compound assignment and explain operator precedence
- Compare values with equality, ordering, identity, and membership operators
- Combine conditions with `and`, `or`, and `not`, and use conditional expressions
- Write clear `if`/`elif`/`else` chains and avoid common indentation mistakes
- Dispatch on values with `match`/`case`, including or-patterns, guards, and `_`
