# Module Overview

This module teaches you how the structures you already use are organized underneath, and how to build the classic structures yourself. You will start with arrays and linked lists, comparing how they store and access items. You will then learn stacks, queues, and heaps for ordering work by position or priority.

After that you will study hash tables, the structure behind `dict` and `set`, and binary search trees for ordered search. The workshop builds a linked list and then a stack on top of it. The lab implements a small binary search tree toolkit with insert, contains, and in-order traversal.

## What You Will Be Able To Do
- Explain the difference between an array and a linked list
- Build a singly linked list with traverse, insert, and delete
- Use a list as a stack and `deque` as a queue
- Use `heapq` to build a min-heap and a priority queue
- Explain how `dict` and `set` use hashing and handle collisions
- Describe the binary search tree invariant and in-order traversal
- Build a stack on top of a linked list
- Implement a binary search tree with insert, contains, and in-order list
