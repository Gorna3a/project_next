# Module Overview

Loops let a program repeat work without repeating code. Python has two loop statements: `for` visits each item in an iterable, and `while` repeats while a condition stays truthy. Between them, they cover counted repetition, condition-driven repetition, and traversal of text.

This module starts with `for` loops and `range`, including start, stop, and step values. It then covers `while` loops, counters, and sentinel values, followed by `break`, `continue`, the loop `else` clause, and `pass`. The final lesson combines nested loops with accumulators to build grids and patterns. The workshop and lab turn these rules into short, deterministic scripts.

By the end, you should be able to choose the right loop for a job, predict how many times it runs, and avoid the off-by-one and infinite-loop mistakes that cause most loop bugs.

## What You Will Be Able To Do
- Write `for` loops over strings and `range` sequences
- Use `range(start, stop, step)` correctly, including negative steps
- Write `while` loops with counters, accumulators, and sentinel values
- Prevent infinite loops by updating the loop variable
- Exit a loop early with `break` and skip an iteration with `continue`
- Explain when a loop `else` block runs and when it is skipped
- Build number and star patterns with nested loops
- Use accumulator and counter patterns to combine loop results
