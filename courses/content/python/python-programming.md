# Course Overview

Python is a readable, general-purpose language used for automation, web development, data analysis, artificial intelligence, and scientific computing. Its clear syntax lets beginners focus on problem solving instead of boilerplate, while its ecosystem supports production-scale applications.

This course takes you from your first printed line to object-oriented design, decorators, algorithms, and core data structures. Each module combines short theory lessons with guided workshops and independent labs, ending with a certification project that brings the skills together.

You will learn by writing real Python code, testing it against clear expectations, and explaining why it works. No prior programming experience is required.

## Learning Objectives
- Write and run Python programs using variables, types, operators, and control flow
- Design reusable functions and model data with lists, tuples, sets, and dictionaries
- Handle exceptions, work with files, and read and write JSON
- Build classes with inheritance, properties, and special methods
- Write Pythonic code with comprehensions, generators, decorators, and context managers
- Analyze algorithms, implement core data structures, and use type hints and tests

## Prerequisite Knowledge
- None. Basic computer literacy only.
