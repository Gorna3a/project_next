# Module Overview

Programs need to remember values: a name, a price, a count, or whether a task is finished. Python stores those values in objects and lets you refer to them with names called variables.

This module introduces the core built-in types you will use in every program: integers, floats, strings, booleans, and `None`. You will learn how assignment works, how to name variables clearly, how strings behave, and how to convert values from one type to another. The module ends with a script that inspects and converts values.

## What You Will Be Able To Do
- Assign values to variables and explain what a name refers to
- Follow Python naming rules and PEP 8 naming conventions
- Create and use integers, floats, and complex numbers
- Index, slice, and transform strings without mutating them
- Recognize truthy and falsy values, including `None`
- Convert values with `type()`, `int()`, `float()`, `str()`, and `bool()`
