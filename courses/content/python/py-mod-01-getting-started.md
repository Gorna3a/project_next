# Module Overview

This module gets Python running on your machine and introduces the habits that keep programs readable. You will learn what Python is, how versions and implementations differ, how the interactive shell compares with a script file, and how indentation and basic syntax shape every program you write.

The focus is on small, complete programs. You will print text, control spacing with `sep` and `end`, add comments, and run a script from the command line. These foundations support every later module.

## What You Will Be Able To Do
- Explain what Python is and where it is used
- Distinguish Python 3 from Python 2 and identify common implementations
- Run code in the REPL and from a script file
- Write correctly indented Python with comments, line continuation, and PEP 8 basics
